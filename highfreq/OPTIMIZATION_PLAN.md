## 🎯 优化方案

### 方案1：Taker订单 + 保守参数（推荐，已实现）

**文件：** `highfreq/run_live_trading_optimized.py`

**优化措施：**

#### 1. 使用Taker订单
- ✅ 立即成交，避免信号失效
- ✅ 虽然手续费0.028%，但胜率提升可能抵消
- ❌ 无返佣，但成交率接近100%

#### 2. 更保守的参数
```python
bias_long=1e-6      # 从5e-7提高到1e-6（更严格，减少信号）
bias_short=-1e-6    # 从-5e-7降低到-1e-6（更严格）
min_depth_total=3.0 # 从2.0提高到3.0（要求更高流动性）
max_spread_bps=1.5  # 从2.0降低到1.5（要求更小点差）
cooldown_sec=15     # 从10秒增加到15秒（减少交易频率）
```

#### 3. 小资金短时间测试
- 资金：$300（从$500降低）
- 时长：30分钟（短时间验证）

**预期效果：**
- 胜率：40-60%（从22%提升）
- 交易频率：20-30笔/小时（从41.5降低）
- 预期收益：-0.5% ~ +0.5%（保守估计）

**运行命令：**
```bash
python highfreq/run_live_trading_optimized.py
```
