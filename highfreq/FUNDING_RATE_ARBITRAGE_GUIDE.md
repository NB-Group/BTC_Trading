# 💰 资金费率套利策略使用指南

## 📊 策略原理

### 什么是资金费率？

永续合约每8小时收取一次**资金费率**（Funding Rate），用于平衡合约价格和现货价格。

- **资金费率 > 0**：做多支付给做空（市场看涨情绪高）
- **资金费率 < 0**：做空支付给做多（市场看跌情绪高）

### 套利原理

当资金费率足够高时（覆盖交易成本），可以通过**现货+期货对冲**来赚取资金费率：

1. **资金费率为正时**：
   - 现货买入 BTC
   - 期货做空 BTC（对冲风险）
   - 每8小时收取资金费率

2. **资金费率为负时**：
   - 理论上可以做空现货+做多期货
   - 但现货通常不能做空，所以只做资金费率为正的情况

### 收益来源

- **资金费率收入**：每8小时收取一次
- **价差收益**：如果现货和期货价差收敛，可能获得额外收益

### 风险

- **价差风险**：现货和期货价差可能扩大
- **资金费率变化**：资金费率可能下降或变负
- **持仓成本**：需要持有现货和期货仓位

## 🚀 使用方法

### 快速开始

```bash
# 默认配置（最小资金费率0.01%，运行24小时）
python highfreq/run_funding_rate_arbitrage.py
```

### 自定义配置

```bash
python highfreq/run_funding_rate_arbitrage.py \
    --capital 1000 \
    --duration 1440 \
    --min-funding-rate 0.01 \
    --leverage 3 \
    --interval 60
```

### 参数说明

- `--capital`: 最大使用资金（美元），默认1000
- `--duration`: 运行时长（分钟），默认1440（24小时）
- `--min-funding-rate`: 最小资金费率（百分比），默认0.01%（即0.0001）
- `--leverage`: 杠杆倍数，默认3x
- `--interval`: 检查间隔（秒），默认60秒

## ⚠️ 重要要求

### 1. **需要现货账户和期货账户**

策略需要同时操作：
- **现货账户**：买入/卖出 BTC
- **期货账户**：做空/做多 BTC 永续合约

### 2. **资金要求**

- 建议至少 $1000 以上
- 需要足够的资金同时持有现货和期货仓位

### 3. **API权限**

需要以下API权限：
- 现货交易权限
- 期货交易权限
- 查询资金费率权限

## 📈 预期收益

### 收益计算

假设：
- 资金费率：0.01%（单次）
- 每天3次资金费率结算
- 年化资金费率：0.01% × 3 × 365 = 10.95%

**成本**：
- 现货手续费：0.1%（买入+卖出）
- 期货手续费：0.028%（开仓+平仓）
- 总成本：约 0.128%

**净收益**：
- 如果资金费率稳定在0.01%，年化约 8-12%
- 但实际收益取决于资金费率的变化

### 风险提示

1. **资金费率可能变化**
   - 资金费率可能下降或变负
   - 需要及时平仓

2. **价差风险**
   - 现货和期货价差可能扩大
   - 可能导致亏损

3. **持仓成本**
   - 需要持有现货和期货仓位
   - 资金占用时间长

## 🔍 策略逻辑

### 开仓条件

1. **资金费率检查**
   ```
   当前资金费率 >= 最小资金费率（默认0.01%）
   ```

2. **成本检查**
   ```
   资金费率 > 交易成本（约0.014%）
   ```

3. **资金检查**
   ```
   可用资金 >= 所需资金
   ```

### 平仓条件

1. **资金费率下降**
   ```
   当前资金费率 < 入场资金费率 × 50%
   ```

2. **持仓时间过长**
   ```
   持仓时间 > 24小时
   ```

3. **价差过大**
   ```
   现货和期货价差 > 2%
   ```

## 💡 优化建议

### 1. **调整最小资金费率**

如果机会太少，可以降低最小资金费率：
```bash

```

如果资金费率变化快，可以缩短检查间隔：
```bash

```

### 3. **调整持仓时间**

如果资金费率稳定，可以延长持仓时间：
- 修改代码中的 `24 * 3600` 为更长的时间

## 📝 常见问题

### Q: 为什么需要现货账户？

A: 资金费率套利需要对冲风险。当资金费率为正时，需要做多现货+做空期货来赚取资金费率。

### Q: 资金费率多久结算一次？

A: 每8小时结算一次（00:00、08:00、16:00 UTC）。

### Q: 如果资金费率变负怎么办？

A: 策略会自动平仓。如果资金费率变负，理论上可以做空现货+做多期货，但现货通常不能做空。

### Q: 预期收益是多少？

A: 如果资金费率稳定在0.01%，年化约8-12%。但实际收益取决于资金费率的变化。

- ✅ 资金充足（建议$1000+）
- ✅ 愿意长期持有仓位

**建议**：先用小资金测试，观察1-2周，如果稳定再逐步加仓。
