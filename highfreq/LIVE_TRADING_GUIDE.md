# 高频策略实盘交易指南

## 🚀 快速开始

### 1. 准备工作

**确保已配置：**
- ✅ `.env` 文件中已填写 OKX API Key
- ✅ 账户中有足够的 USDT 余额（建议至少 500 USDT）
- ✅ API Key 有交易权限

### 2. 运行实盘交易

#### 方式1：使用默认参数（推荐）

```bash
# 实盘模式（会真实交易）
python highfreq/run_live_trading.py

# 模拟模式（不真实交易，用于测试）
python highfreq/run_live_trading.py --demo
```

#### 方式2：自定义参数

```bash
# 自定义资金、时长等
python highfreq/run_live_trading.py \
    --capital 500 \
    --duration 60 \
    --interval 1.0 \
    --use-taker
```

**参数说明：**
- `--capital`: 最大使用资金（美元），默认 500
- `--duration`: 运行时长（分钟），默认 60
- `--interval`: 检查间隔（秒），默认 1.0
- `--use-taker`: 使用 Taker 订单（默认使用 Maker 订单）
- `--demo`: 模拟模式（不真实交易）

### 杠杆设置

**自动计算最优杠杆：**
- 基于最小开仓价格和最大资金
- 公式：`最大杠杆 = 最大资金 / 最小开仓价格`
- 限制在 OKX 允许的最大杠杆内（通常 125x）

**示例：**
```
最大资金：$500
最小开仓：1张 × $100 = $100
最优杠杆：500 / 100 = 5x
```

## ⚠️ 风险控制

### 1. 资金限制

- **最大使用资金：** $500（可在启动时调整）
- **单笔交易：** 根据可用资金和杠杆自动计算
- **最小开仓：** 1张（合约要求）

### 2. 止损机制

- **止盈：** 0.10%（价格达到即平仓）
- **止损：** 0.12%（价格达到即平仓）
- **时间止损：** 30秒（持仓超过30秒强制平仓）

### 3. 冷却期

- **冷却时间：** 10秒（平仓后10秒内不开新仓）
- **目的：** 避免过度交易

### 4. 市场过滤

- **深度过滤：** 总深度 < 2.0 BTC 时不交易
- **点差过滤：** 点差 > 2.0 bp 时不交易

## 🛠️ 故障处理

### 常见问题

#### 1. API 限流

**症状：** 频繁出现 "Too many requests" 错误

**解决：**
- 程序已内置重试机制（指数退避）
- 如果持续限流，考虑增加 `--interval` 参数（如改为 2.0 秒）

#### 2. 资金不足

**症状：** "可用资金不足" 警告

**解决：**
- 检查账户余额
- 降低 `--capital` 参数
- 确保账户有足够的 USDT

#### 3. 订单未成交（Maker 订单）

**症状：** 开仓后长时间未成交

**解决：**
- 使用 `--use-taker` 参数（立即成交，但需要支付手续费）
- 或等待价格回调到挂单价

#### 4. 强平风险

**症状：** 账户权益接近维持保证金

**解决：**
- 立即停止程序（Ctrl+C）
- 检查仓位，手动平仓
- 降低杠杆或减少资金使用
