# BTC Trading Promo

Project promotion video generated using native web technologies (SVG + CSS + JS).

## Features
- **Pure DOM/SVG**: No Canvas, ensuring crisp vector graphics at any resolution.
- **Morandi Palette**: Artistic and soft color scheme.
- **Scene Engine**: Lightweight JS animation framework.
- **Bilingual Support**: English and Chinese subtitles.

## How to Run
1. Open `index.html` in a modern browser.
   OR
2. Run a local server:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000/btc_promo/`

## Scenes
1. **Intro**: Introduction to Bitcoin concepts.
2. **K-Line Visualization**: 
   - Candle formation (Open/High/Low/Close).
   - Chart generation.
   - Technical indicators overlay (MA, Bollinger Bands, Volume).
